# fuplus-tools

符加项目的周边工具合集——把日常使用中"不顺手"的点子，做成能直接拿来用的小工具。

A collection of small, practical utilities born from the fuplus (符加) desktop-AI-companion project. Each tool solves one concrete annoyance.

## 工具清单 / Tools

| 工具 | 一句话说明 | 状态 |
|---|---|---|
| [quickshot](./quickshot/) | Windows 一键截屏进剪贴板（F9 全屏 / F10 活动窗口），自动存档，开机自启 | ✅ 可用 |

## 工作方式

每个点子先在 Issues 里立项，由 AI 结对实现+评审，人拍板后合并发布。详见各工具目录的 README。

## 贡献者 / How this is built

本仓库是人机协作产物，分工如下：

- **lotuswu2580-dev**（人）——点子、需求拍板、验收
- **Kimi Code（K3）**（AI）——实现
- **Sol / Codex**（AI）——独立评审（专测失败场景）

AI 贡献以 `Co-authored-by` 提交尾注留痕，见各次提交记录。
